# RISC-V OoO en FPGA: Original, Lite e Improved

El proyecto estudia el comportamiento **microarquitectónico** y la implementación mediante **Vitis HLS / Vivado** de un procesador RISC-V de ejecución fuera de orden (*Out-of-Order*, OoO).

Se parte de una arquitectura **Original** y se desarrollan dos variantes: **Lite**, orientada a reducir recursos, e **Improved**, orientada a aumentar el paralelismo interno.
